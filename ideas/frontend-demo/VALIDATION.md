# Validación de entregable frontend (NO presupone compilación)

La aplicación Angular **no forma parte** de este paquete: se generará con el prompt y los CLI oficiales. No atribuir a esta carpeta una ejecución de `ng build` ni pruebas que aún no se han realizado.

Requisitos de entrega del agente implementador:
- `ng build`, `ng test` y E2E ejecutados con registro de fecha, comandos, salida resumida y artefactos.
- Smoke tests: 375/768/1280/1440 px, navegación sin APIs, persistencia mock y recuperación tras refresh.
- Flujos de ciberseguridad: replay con mismo `bootId+sequenceNumber` rechazado; inconsistencia física abre investigación, **no confirma ataque**.
- Misiones: estados + aprobaciones; condiciones inseguras bloquean despacho (solo simulación).
- Auditoría de tenant DEMO, sin prometer aislamiento de servidor.
- Datos sobre imagen tipo satélite y vuelo de dron identificados como ilustrativos.

# Fixtures y contrato de frontend demo

Esta carpeta contiene muestras estructurales para Angular, **no una aplicación ya implementada**. La IA debe construir mocks tipados y persistentes a partir de la fuente JDL.

- `demo-fixtures.example.json`: datos sintéticos y escenarios. ID demo nunca implica entidad real.
- `entity-to-ui.csv`: cobertura de las 47 entidades del JDL.
- `navigation.example.json`: rutas recomendadas con roles DEMO.
- `design-tokens.tailwind-v4.css`: propuesta de tokens, adaptar a configuración Tailwind instalada.
- `acceptance-scenarios.md`: escenarios y QA de negocio.
- `VALIDATION.md`: evidencia exigida antes de declarar frontend terminado.

No conectar a backend ni APIs de clima durante la demo. **Mock role checks no garantizan seguridad multiempresa real.**

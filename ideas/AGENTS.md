# Reglas de implementación para cualquier agente

1. Leer `README.md`, `specs/domain.v4.draft.jdl`, `docs/00_ARQUITECTURA_MAESTRA_SDD.md` y `docs/06_SEGURIDAD_TELEMETRIA_ATAQUES.md` antes de cambiar código.
2. Para la hackatón ejecutar `prompts/PROMPT_MAESTRO_IA_FRONTEND_ANGULAR_MOCK.md`: Angular standalone + Tailwind, mocks locales, sin backend.
3. **JDL es borrador**, no compilar/validar sin registrar ejecución real. No inventar 47 CRUD; mapear entidades a flujos.
4. No afirmar imágenes térmicas satelitales de paneles. No afirmar autenticidad de lecturas sin controles verificables.
5. No desplegar drones/actuadores reales; permisos y controles de seguridad antes de misiones.
6. Identidad visual `docs/04_DESIGN_SYSTEM_QUEBRADA.md`; usar skills locales u oficiales verificadas; documentar licencias.
7. Cada funcionalidad necesita spec, casos límite, test, demo y evidencia. Declarar resultado no ejecutado como NO VERIFICADO.
8. No filtrar datos ni fotos entre tenants; simulación frontend no equivale a backend seguro.
9. NUNCA tocar código del dashboard existente sin inventario, respaldo y verificación de paridad.
10. Preservar la integridad de los archivos y no crear rutas antiguas ni duplicados de versión.

# Simuladores HTML independientes

Se incluyen tres HTML autocontenidos provenientes de las exploraciones del proyecto, reetiquetados HelioGuard.

- `helioguard_lab.html`: laboratorio de datos, clima y métricas; demo ilustrativa.
- `helioguard_flow.html`: secuencia de aviso → técnico/dron/propietario → intervención.
- `helioguard_orbit.html`: parque solar en vista cenital, dron/técnico, seis escenarios y **módulo extra de replay/inconsistencia** con comprobaciones JavaScript locales.

**No representan termografía satelital real ni control de hardware.** No están integrados con el JDL ni constituyen el frontend Angular; son referencias visuales/funcionales que se pueden reutilizar tras auditoría de calidad.
